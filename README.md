This study investigates the role of pantothenate transporters in fungal pathogenesis using a transcriptomics-based approach in Verticillium dahliae. The research employs next-generation sequencing (NGS) and comprehensive bioinformatics analyses to compare gene expression profiles between wild-type strains and a pantothenate transporter gene knockout mutant (liz1/VDAG_02269). The overall objective is to understand how disruption of pantothenate uptake influences global transcriptional regulation associated with fungal pathogenicity.

Paired-end RNA-seq data were obtained from publicly available datasets generated from both control and mutant strains, with three biological replicates per condition. Prior to analysis, raw sequencing reads underwent quality control procedures to remove adapter sequences, low-quality bases, and technical artifacts. Sequence quality was evaluated using Phred quality scores to ensure high-confidence base calling. Cleaned reads were then aligned to the Verticillium dahliae reference genome (v1.0) using HISAT2, an efficient splice-aware aligner based on the Burrows–Wheeler Transform and FM-index.

Transcript assembly and quantification were performed using StringTie, which reconstructs full-length transcripts and estimates expression levels while accounting for alternative splicing. Assembled transcripts from all samples were merged to generate a unified transcriptome annotation, followed by comparison with the reference annotation using GffCompare. Gene-level expression counts were generated and used for downstream statistical analysis.

Differential gene expression analysis was conducted using the DESeq2 framework, which models count data and normalizes expression across samples. Functional annotation and enrichment analyses, including Gene Ontology and pathway analysis, were incorporated to interpret transcriptional changes at the systems level. All analyses were implemented through a modular Python-based RNA-seq pipeline, ensuring reproducibility and workflow automation. This methodological framework provides a robust platform for studying nutrient transporter–mediated regulatory mechanisms in fungal pathogens.
